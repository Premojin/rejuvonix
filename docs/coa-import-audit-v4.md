# Rejuvonix Protocol COA Import Audit — Surgery v4

## Locked rules

- FDA-approved finished drug products use official prescribing documentation; COA not required.
- Other protocol items may display a COA only after an exact item/certificate match is verified.
- Imported certificates are stored locally and shown without adding third-party branding to the surrounding Rejuvonix interface.
- Original certificate files are never altered to remove names, logos, results, dates, lots, laboratories, or other provenance.
- No substitute certificate is accepted solely because it tests a similarly named compound.

## Current package state

The build is import-ready. Certificate slots remain pending unless an exact source certificate has been obtained and imported. This runtime does not expose a browser capable of retrieving the source catalog's protected/dynamic certificate downloads, so no certificate has been guessed or substituted in this package.
